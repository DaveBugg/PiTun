Introduction

libsleep is a tiny Python library that replaces time.sleep with a deterministic clock for unit tests. No threads, no real wall-clock, no flaky timing assertions.

The problem

Suppose you have a function that retries with exponential backoff:

def retry(fn, max_attempts=5):
    for i in range(max_attempts):
        try:
            return fn()
        except Exception:
            time.sleep(2 ** i)
    raise

Testing this realistically takes 1+2+4+8 = 15s per failed call. You either patch time.sleep with MagicMock() (loses the cumulative-time invariant) or you use freezegun (heavyweight, slow on import).

The solution

libsleep exposes a FakeClock that replaces time.sleep for the duration of a context. Calls record requested durations into a virtual clock you can advance manually:

from libsleep import FakeClock

with FakeClock() as clk:
    retry(flaky_func, max_attempts=4)
    assert clk.elapsed == 7.0  # 1+2+4
Note. libsleep doesn't patch asyncio.sleep. Use the companion libsleep.aio module — see the Async support guide.

Installation

pip install libsleep

Python 3.9+ is required. No mandatory dependencies; pytest is suggested for the included plugin.
